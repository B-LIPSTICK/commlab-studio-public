# 新版实验台（工作台）

## 是什么

我们自己的画布，不加载润尼尔的网页。器件目录来自平台器件定义的抽取结果，运行仍走 9002 引擎。

入口：主界面「新版实验台」；旧入口改名「老版实验台」，原样保留。

## 结构

```
app/workbench/
  index.html      顶栏 / 器件栏 / 画布 / 属性栏 / 结果抽屉
  workbench.css   纸质 + 墨色，日间夜间双主题
  workbench.js    画布交互与运行
  preload.js      devices / runGraph / openLab
app/graph.js       画布图 → Octave 脚本（拓扑排序 + 输入映射）
data/devices.json  74 个器件：类名、中文名、输入口、输出口、分类
```

## 交互

- 左侧点器件 → 落到画布
- 拖拽移动；点输出口再点输入口 → 连线（贝塞尔）
- 点连线删除；选中器件按 Delete 删除
- 运行：拓扑排序后生成脚本，发 9002，结果抽屉里渲染 SVG

## 器件分类

按类名前缀归组：信号源 / 线路码型 / 调制与解调 / 滤波与信号变换 /
信源与信道编译码 / 通用器件 / 观测与分析 / 信道与均衡。

## 已知限制

- 器件参数暂用 .m 默认值，还没有属性表单
- 不能保存/打开 .ocj（下一步）
- 画布没有缩放与框选
